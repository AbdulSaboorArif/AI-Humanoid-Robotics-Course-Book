# Code Examples for Physical AI & Humanoid Robotics Course

This directory contains runnable code examples that accompany the Physical AI & Humanoid Robotics course book. Each subdirectory corresponds to a specific technology or module covered in the course.

## Directory Structure

- `ros2/` - ROS 2 code examples and packages
- `gazebo/` - Gazebo simulation examples and world files
- `unity/` - Unity simulation examples and assets
- `isaac/` - NVIDIA Isaac platform examples
- `capstone/` - Capstone project code and resources

## Prerequisites

Before running the examples, ensure you have:

- ROS 2 Humble Hawksbill (or later) installed
- Gazebo Garden (or compatible simulation environment)
- Python 3.8+ with required packages
- NVIDIA Isaac ROS packages (for Isaac examples)
- Appropriate hardware or simulation environment

## Running Examples

Each example directory contains its own README with specific instructions. Generally, the process follows this pattern:

1. Navigate to the example directory
2. Source your ROS 2 workspace: `source /opt/ros/humble/setup.bash`
3. Install dependencies if needed
4. Run the example using the provided launch files or scripts

## Contributing

When adding new examples:
- Follow the existing directory structure
- Include comprehensive README files
- Ensure examples are self-contained and well-documented
- Test examples in the specified environment
- Follow the same coding standards as the course content
